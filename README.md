# Orbe Convoy

Live map of every car in your group on a road trip, with a warning when someone falls behind.

- **Android app:** [Download OrbeConvoy.apk](https://github.com/nishantbansal34-star/Convoy/releases/latest/download/OrbeConvoy.apk). It keeps sharing location with the screen off.
- **Web version:** https://nishantbansal34-star.github.io/Convoy/ (keep the page open while driving)

Everyone joins with the same trip code. Live positions are relayed through Supabase Realtime and are not stored.
